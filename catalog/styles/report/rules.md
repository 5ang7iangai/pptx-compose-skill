风格：行业汇报（政府部门、行业协会的工作汇报：浅底细边圆角框、虚线分组、深色粗箭头表示数据流、按层级/类别用不同颜色编码）

- 框：浅色填充 + 同色系 1.2–1.5 细边，rx 6–8；重要的框可加很淡的阴影（feDropShadow dy 2、stdDeviation 3、透明度 0.10）。不用大面积深色实底。
- 颜色编码：同一张图里不同层级/类别各用一套「深色 + 浅底」，同一级的标题、边框、图标、文字强调保持同一套色：
  - 第一类（最高层级或核心对象）：{dominant} 配 {light}；
  - 第二类：{c2} 配 {c2l}；
  - 第三类：{c3} 配 {c3l}。
  类别超过三种时，其余用 {mid} 配 {paper}。
- 标题：分组/类别标题用实底小标题条（该类深色底、白字粗体，rx 4–6），或该类深色粗体文字加左侧小图标。
- 分组：用同色系虚线框（stroke-dasharray="5 4"，线宽 1.2，rx 8）把同一组的条目框起来。
- 数据流：用 {dominant} 粗箭头（线宽 5–7 的直线 + marker 三角），方向表示数据上送或下发；箭头旁用 {mute} 小字（比正文小 1–2 号）写传输内容，如「档案数据、运行数据、告警数据」。普通关联用 {line} 细线。
- 说明文字可以两三行，关键词用 tspan 改成该类深色并加粗。要点前可用「◆」或小圆点。
- 图标：该类深色的圆底 + 白色线条小图形，或该类深色线条图形无底；同一张图图标风格一致。
- 整体是白底，留白均匀，信息密度可以高，但每块都要对齐成行成列。
