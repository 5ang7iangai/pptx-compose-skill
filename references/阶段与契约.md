# 阶段与契约

当次任务工作区（不进技能包）：

```text
<任务目录>/
├── 模板.pptx          # 用户上传
├── 材料/ …
└── run/
    ├── manifest.json
    ├── 风格卡.json              # prepare
    ├── outline.json             # 助手（亦认 S3_大纲.json）
    ├── pages.json               # 助手（亦认 S4_页面正文.json / S5_正文_审后.json）
    ├── 中间稿.pptx               # assemble
    ├── diagram_jobs.json         # assemble
    ├── assemble_report.json      # assemble 可选核对
    └── diagrams/
        ├── <label>-<name>.svg    # 助手；文件名与 diagram_jobs[].svg 一致
        └── …
├── <中文题目>-图片版.pptx
└── <中文题目>-可编辑版.pptx
```

可选助手落盘（不强制）：`S1_摘要.json`、`S2_视觉理解.json`、`S5_审查.json`。

## 谁写谁读

| 文件 | 写 | 读 |
|---|---|---|
| manifest.json | prepare / 各阶段更新 status | 全部 stages、助手 |
| 风格卡.json | prepare（profile_deck） | 助手出图配色、assemble |
| outline / pages（或 S3/S4） | **助手** | assemble |
| diagram_jobs.json | assemble | apply_diagrams |
| diagrams/*.svg | **助手** | apply_diagrams、add_chapter、redraw |
| 中间稿.pptx | assemble | apply_diagrams |
| 两套 pptx | apply_diagrams / add_chapter / redraw | validate、用户 |

Schema / 样例见 `schemas/`。

## assemble CLI

```bash
python scripts/stages/assemble.py --run <任务>/run [-o <任务>/run/中间稿.pptx] [--template 模板.pptx]
```

- 读 `manifest.template`（或 `--template`）、`风格卡.json`、`outline.json|S3_大纲.json`、`pages.json|S4_…`
- 写出 `中间稿.pptx`、`diagram_jobs.json`（每项含 `slide`、`diagram`、`svg` 文件名）
- 有旧 review 图的样例页：即使本页无图也会 `clear_region`
- 正文页填字后对顶栏页签调用 `relayout_section_tabs`（gap=0）

## apply CLI

```bash
python scripts/stages/apply_diagrams.py --run <任务>/run -o <任务>/<中文题目>.pptx
```

缺 SVG 时按**页码**列出后退出；不调用外部模型。

## 阶段状态（manifest）

字段：`template`、`materials[]`、`title`、`stages.{prepare,text,assemble,diagrams,apply,validate}`、`outputs.{图片版,可编辑版}`、`intermediate`、`diagram_jobs`。
