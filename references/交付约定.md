# 交付约定

1. **两套同源**：同一份已检查的 SVG →  
   - `<中文题目>-图片版.pptx`（4× PNG 贴图）  
   - `<中文题目>-可编辑版.pptx`（DrawingML「结构图」组合）  
2. **基准名**用封面中文题目；非法文件名字符去掉或替换。不用技能英文 id、内部代号（用户明确要求除外）。  
3. **不覆盖**用户上传的模板/现稿；输出必须是另一路径。  
4. **校验不过不交付**：`validate_deck` / `checks/run_all.py` 退出非 0，或 `diagrams[].problems` 未处理，不得把文件当完成品交给用户。  
5. 过程目录（`run/`、临时预览 PNG）默认不塞进交付包；需要调试可保留 `run/`。  
6. 有结构图时两版都要过三层校验（见 [校验与验收.md](校验与验收.md)）。
