# 公开发布脱敏

每次把本技能推到 GitHub 或打成网盘压缩包前执行。

## 禁止出现

1. 真实单位/组织名、客户名、内部处室或项目代号。
2. 真实汇报/成稿题目；能指向当前课题或业务现状的专有词。
3. 用户姓名、联系方式、本机路径、密钥、私有 URL。
4. 单位模板 pptx、真实材料、任务目录产物。

## 允许

- 通用占位：「一、背景与目标」「二、实施方案」；顶栏例「现状梳理 | 路径设计 | 试点验证 | 推广安排」。
- 技能自身流程示意（智能演示文稿助手输入/输出）。
- 抽象行业中性示意（总部/区域/站点；协作/数据/应用），勿写可识别的在办项目。

## 步骤

1. 全包文本扫描（组织名、人名、课题词、路径、邮箱）。
2. 必要时改 `references/`、`prompts/`、`catalog/styles/*/example.svg` 与 `catalog/图库.html`（图库与示例 SVG 须一致）。
3. 重打 `pptx-unit-YYYYMMDD.zip` / `.tgz`。
4. 同步更新 GitHub 仓库内容与 README/描述，并回传压缩包供网盘上传；两边同版本。
