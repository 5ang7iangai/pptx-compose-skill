# 整套新编

用户给模板和一堆材料（docx / pdf / pptx / md / txt），要一份新的汇报稿。

**本技能不提供一键 HTTP 编排。** 按 [workflows/compose.md](../workflows/compose.md)：

```text
python scripts/stages/prepare.py --template 模板.pptx --materials 材料.docx … -o 任务目录
# 助手写 run/outline.json、run/pages.json（页纲确认后；可选 S1/S2/S5）
python scripts/stages/assemble.py --run 任务目录/run
# 助手写 run/diagrams/*.svg
python scripts/stages/apply_diagrams.py --run 任务目录/run -o 任务目录/<中文题目>.pptx
python scripts/stages/validate.py 任务目录/<中文题目>-图片版.pptx 任务目录/<中文题目>-可编辑版.pptx --original 模板.pptx
```

`-o` / 交付基准名用**封面中文题目**。实际交付为 `<基准名>-图片版.pptx` 与 `<基准名>-可编辑版.pptx`。


## 过程文件（run/）

见 [阶段与契约.md](阶段与契约.md)。提示词在 `prompts/text/`，由助手写入 JSON。

### 字数怎么定（样例页容量）

写页纲之前，助手与 `stages/assemble` 用 `pptkit/autofill.page_capacity` 量出每个正文样例页的原标题、导语框字数和行数（按字号和框宽算每行字数）、每张卡片字数、有没有图区，列给页纲选 `clone_from`；封面标题框能放几个字（`cover_title_room`，不换行的框只有一行）也写入页纲提示。页纲落盘后 `fit_outline`（assemble 内）按所选样例页改写 `text_plan`：

- 卡片页：要点条数 = 卡片数，每条约等于卡片原字数，不写子要点；
- 单框页（导语和要点都写进一个框）：导语约占四成，要点最多 4 条，合计不超过原框字数；导语和每条要点各占一段、段尾不满也占一行，所以还按行数卡：导语至少一行，要点条数 ≤ 原行数 − 1，每条不超一行。只卡字数时，3 行的框写进导语加 3 条短要点会变 4 行，压到下方图区；
- `max_total_chars` 是全页上限，撰写 `pages.json` 与可选审查都按它控字数。

`clone_from` 不是正文样例页时（比如选了封面），自动换成正文页，要图的优先换有图区的页，并打警告。手改 `run/outline.json`（亦认 `S3_大纲.json`）后重跑 `assemble`，会按新的 `clone_from` 重算字数。

### 提示词与落盘约定

- 助手按 `prompts/text/` 写**紧凑 JSON** 到 `run/outline.json`、`run/pages.json`（脚本亦兼容旧名 `S3_大纲.json` / `S4_页面正文.json` / `S5_正文_审后.json`）；
- 页纲优先写事实编号（`key_facts_to_use: ["F2","D1"]`），撰写正文时由助手对照材料换回原文；
- 字数由 `page_capacity` / `fit_outline` 约束，不要估字数硬塞；
- 结构图修补时上一版 SVG 已体现风格，不必再附风格范例 SVG。

## 调试

- 改 `run/outline.json` / `run/pages.json`（或兼容旧名）后重跑 `stages/assemble.py`。
- 改 `run/diagrams/*.svg` 后重跑 `stages/apply_diagrams.py`（再 `validate`）。
- 只要文字、暂缓贴图：助手可不写 SVG，或 assemble 后只交付中间稿核对排版，再补图。
- 图检查不过：助手按 `fix_svg.md` 改磁盘 SVG 后重跑 apply；`--regen`/`--fix` 在本技能**不调模型**，仅提示改文件。

## 文字怎么填进样例页（认槽）

`pptkit/autofill.py` 在克隆来的页上找这几类文字槽：

- **标题**：标题占位符（包括位置继承自版式、页上没写坐标的）；没有就取页面上部 22% 内最靠上、宽度超过页宽 10%、不超过 40 字的文字（「1.1工作要求」这类窄标题只有 15% 宽，标题下方的页签约 7%）。封面放宽到上部 60%、宽度要超过 20%，且只换标题；封面标题按 `fit_cover_title` 收窄到不超过页宽 75%、放不下就按语义断成两行、在原区域上下居中（细则见 [文案与目录.md](文案与目录.md)「封面标题」），报告记 `cover_title`。封面标题以下的单位、日期，页纲里写了 `subtitle` 就换上，没写就清掉，避免留下模板上一家的落款；报告记 `subtitle_cleared`。
- **小节**：标题下方、仍在上部 22% 内的另一行短文字。行业模板常见两级：顶栏写章名「二、……实践情况」，下面写「（一）整体思路」。认出小节时，页纲的 `section` 写顶栏、本页 `title` 写小节；没有小节的模板照旧只写标题。
- **图注**：正文区里没被当成槽的短文字（≤ 30 字），多是旧图旁的说明（如竖排的「智能体数据接入概览」）。这页要清旧图时一起删，报告记 `captions_cleared`。
- **卡片**：宽度不小于页宽 20%、彼此宽差 < 30%、高差 < 20% 的一组文字框（至少 2 个，取最多的一组），按先上后左排序。要点按顺序填进去，只放主句。
- **导语**：其余宽度不小于页宽 30% 的文字里面积最大的。没有卡片时，导语和要点收成一段写在这里，并套风格卡里的正文样式，不沿用框里原来各段不一样的字。
- **备注**：写进备注页。

样例页上的旧示意图（风格卡 `kind=review` 的图片）一律清掉，图区取这些旧图的外接框。顶栏标志、通栏页脚、铺满整页的底图不算进这个框，上方的章名和导语留着。没字、几乎通栏、从标题下铺到页脚上的大底框是正文背景，清图时留下。没有内容图时用正文区右半边。

## 目录页

模板有目录页、且条目认得出时，封面后留第一份。识别两种模式（`toc_entry_count` / `toc_mode`）：
- **模式 A**：编号徽标「01」/「1」+ 同一行右侧章名；
- **模式 B**：文本匹配「一、章节名」的条目行（排除「目录」「CONTENTS」），常见于单位模板无独立徽标。
`toc_entry_count=0`（两种都认不出）时 **assemble 必须失败退出**，禁止静默留下模板旧章。模板里这种目录页出现不止一次（章与章之间也有）时，每一章正文前都再放一页。`fill_toc` 按页纲各页 `section` 去重后的顺序重写条目（模式 B 写成「一、xxx」）；每一页 `current` 标出该目录后的那一章：少数派样式=当前章，多数派=普通。条目若在组合内，填充时拆到 spTree 用绝对坐标排布。

- 条目排好后整组上下居中（`slides.center_toc`）：对齐左侧「目录 / CONTENTS」的纵向中心，认不出时对齐页面中心；报告 `toc.centered` 记平移量。条目变少时不能还从模板顶部排起；
- 以第一行条目为样板克隆，行距取原行距，章多时在原条目区到页面 85% 之间均匀压缩，报告 `toc.crowded` 表示比编号徽标还挤；
- 编号已在徽标里，章名去掉「一、」这类序号；按字号估算一行放不下时去掉末尾括号注释，仍放不下记 `toc.too_long`；
- 克隆时去掉插件写的形状标签（`p:custDataLst`）：一个标签部件只能被一个形状引用，共用会让 PowerPoint 打不开文件，`validate_deck` 查不出来。

条目认不出的目录页（比如整页是一张图）直接删掉。

目录当前章高亮必须「强调填充 + 对比字色」成套；克隆条目后若同时存在 `noFill` 与 `solidFill`，去掉 `noFill`（`slides._sanitize_sp_fill`）。

正文样例页顶栏/侧栏的旧章节导航（页签）在填字后改成新大纲章名并按 `section` 高亮，见 [文案与目录.md](文案与目录.md)。

## 报告

脚本打在屏幕上的结果里，`filled` 按页记录：

| 字段 | 意思 |
|---|---|
| `title` / `subtitle` / `section` / `intro` / `cards` | 填进了哪个形状（`subtitle` 是小节、`section` 是顶栏章名） |
| `bullets_dropped` | 要点比卡片多，没放下的要点 |
| `overflow` | 文字明显长于原槽（超过原字数 1.3 倍且多 20 字以上），或导语框行数超过原行数，或封面标题超出一行，可能溢出 |
| `captions_cleared` | 随旧图一起删掉的图注 |
| `subtitle_cleared` | 封面上没被替换、因而清掉的单位或日期 |
| `notes` | 写了备注 |
| `cover_title` | 封面标题的排法：`lines` 几行、`sz` 字号、`width_ratio` 框宽占页宽、`fits` 是否放下 |

屏幕输出顶层的 `toc` 记目录页：`entries` 条数、`step` 行距、`crowded`、`too_long`、`centered`（整组居中的锚点和平移量）。`missing_pages` 记模板缺的封面或目录页型，非空时写进交付说明。

页纲里同一章平级的小节每个单独成页、用同一类样例页（`outline_pages.md` 第 8 条）。`outline.json` 落盘后检查一遍：后几项被并成一页纯文字的，拆开、改 `clone_from` 后重跑 `assemble`。

`bullets_dropped` 和 `overflow` 非空时要处理：换一张卡片更多的样例页（改 `clone_from`），或在 `pages.json`（亦认 `S4_页面正文.json` / `S5_正文_审后.json`）里删短后重跑 `assemble`，或出稿后用 `slides.py duplicate-shape` 加卡片。`diagrams` 里每张图的 `problems` 同加一章。

## 已知局限

- 认槽是按几何规则猜的，版式特别的样例页可能认错；报告里看每页填进了哪个形状，不对就换 `clone_from`。
- 要点多于卡片数时直接丢弃（记在 `bullets_dropped`），不会自动复制卡片。
- 文字超出原槽只报告，不自动缩字号。
