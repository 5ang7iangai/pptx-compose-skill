# 校验与验收

三层：包是否完整、改动是否到位、逐页看。前两层不过，不把文件交给用户。有结构图时两版都要过。

有结构图任务时，交付前还必须过 **版式策略终检**：`python scripts/layout_policy.py check-run --run <run目录>`（或 `stages/validate.py … --run <run>` / `checks/run_all.py … --run <run>`）。不过则不交付。

## 1. 包是否完整（脚本）

```text
python scripts/validate_deck.py 编制-图片版.pptx   --original 模板.pptx
python scripts/validate_deck.py 编制-可编辑版.pptx --original 模板.pptx
# 或
python checks/run_all.py 编制-图片版.pptx 编制-可编辑版.pptx --original 模板.pptx
```

- 是合法 pptx，幻灯片列表和零件对得上；关系指向的备注、版式、图片都还在。
- `--original` 去掉模板里原本就有的关系问题，只看这次新出现的。图表链接到作者电脑上的外部 Excel（`TargetMode="External"`）不算缺件。
- 退出码非 0 就先改脚本产物，不手改坏掉的 XML。

指定页面必须出现的句子、某一页必须有可编辑结构图：

```text
python scripts/validate_deck.py 编制-可编辑版.pptx --original 模板.pptx --require-text "2:四、新章节" --diagram-slide 24
```

`--diagram-slide` 仅适用于旧式粘连连接符图；助手 SVG 转出的连线是自由线段，通常不加此参数。

## 2. 改动是否到位（报告 + 脚本）

先看脚本打在屏幕上的结果：

- `diagrams[].problems` 为空才算图过了检查；不空则助手按 problems 改 SVG 后重新 apply，或说明原因。单张复查：`python scripts/svg_diagram.py check 图.svg --style <风格> --brief 图意.json`（带 `--brief` 才查字号下限和画重）。
- 加一章看 `toc`：每份目录都加上了，`status` 不是 `overlap`。
- 重做原稿看 `cleared`：每页清掉的形状数合理，导语没被清。
- 整套新编看 `filled`：`bullets_dropped`、`overflow` 为空（见 [整套新编.md](整套新编.md)）。
- `checks` 为空。有内容表示正文、表格或图表的字体和模板学到的那一套不一致，或者没有卡片的正文被拆成了多句分行。
- **导语/正文与结构图不得重叠**（全稿自动扫，不得静默通过）：`validate_deck.py` 会调用 `pptkit.layout_check.text_diagram_overlaps`，逐页检查导语框与内容图/「结构图」是否相交、导语字数是否超出框高而溢到图上。有问题就进 `errors`、退出码非 0。贴图时 `diagram.place.add_picture` / `add_editable` 也会先 `assert_bbox_clears_intro`（图顶须在导语有效底边之下并留 ≥0.15″ 间隙）。修法：删短导语，或加大导语框并下移 bbox/结构图。

再对照：

- 新页上不残留样例页里被替换掉的原句。**标识/logo 可留**；顶栏/侧栏**旧章节页签必须改成新大纲章名并高亮当前章**，不得残留与目录无关的旧章名。
- 新页在致谢页之前；点名保留的页，文字和图片与原件一致。
- 要求画成形状的区域里图片已去掉，组合名是「结构图」，节点文字能读到。

## 3. 逐页看（人）

```text
python scripts/preview.py 编制-图片版.pptx   预览/
python scripts/preview.py 编制-可编辑版.pptx 预览/
```

用本机 PowerPoint 导出 1600×900 PNG（仅 Windows）。两版逐页对比，应几乎一样。看完把预览目录删掉。脚本不判定逻辑，交卷前自己看：

- 写作要求里的章节都有着落，顺序一致；加一章时旧章编号没有被顺带改掉。
- 没有材料里不存在、又没标「待核实」的数字和部署结论。
- 目录新条目的间距、字号、字色、对齐和同列旧条目是一套。当前章高亮是填充+字色成套，白字不会留在无填充/浅底上（像少了一章）。
- 交付文件名是封面中文题目加「-图片版/-可编辑版」，不是英文短名或内部代号。
- 正文页导语下主内容横向铺满或居中，无「一侧有内容、对侧大片空」；`validate_deck` 会跑 `content_band_narrow`。目录/封面/致谢除外。
- 并列卡无空壳（标题+说明）；同行流程/时间轴节点等宽（含强调色块）；导语与图间隙≥0.15″；结构图标题/正文有对比度层级，禁止同为浅色。
- 导语与卡片面向正式汇报、表述完整；重点词已加粗或主色强调。
- `validate_deck` 已跑 `empty_shell_cards`、`peer_row_widths`、加强后的 `text_diagram_overlaps`；出图 checks 含 `card_title_body`、`peer_equal_widths`、`contrast_hierarchy`。不过检不得交付。
- 顶栏章节页签已重排成连续导航：相邻 **edge-to-edge（gap=0）**，无留缝、无重叠；高亮章正确。`validate_deck` 跑 `section_tabs_gaps`。
- 正文页签文字**完整可见、单行平铺、无截断/溢出**；宽度已兼容本组长名（或向右扩展/略缩字号至 ≥85%）；相邻 gap=0。
- 正文页签与目录四章一致，当前章页签已高亮。
- 目录条目整组上下居中（对齐「目录 / CONTENTS」或页面中心），条目变少时没有挤在上方、下面空一大块；每页目录高亮的是它后面那一章。
- 封面标题没有横向占满整页：框宽不超过页宽约 75%、左右居中；超长的按语义断成两行，没有断在词中间；不压装饰线和底图。
- 同一章平级的小节各自成页、页型一致（都有导语和图，或都没有），没有把后几项并成一页纯文字。
- 封面和目录都在；模板缺页型而没生成的，交付说明里写明了。
- 导语字数接近样例页，能看懂场景、问题和做法；没有「套版」「搬字」「风格卡」「克隆」这类制作词。
- 图有分区、标题、图标、卡片说明，不是一排没有说明的方块；字不比原页正文小，行距不挤；重做原稿时结构大致跟原图。
- 可编辑版里文字行没有叠在一起，箭头头部大小正常。
- 每一页导语框（及正文文字区）都不被结构图/贴图盖住；图顶贴齐导语框底且字放得下可以，图顶伸进框内或字溢出到图上不行。脚本已扫过仍要肉眼扫一眼。
- 图下方露出母版底纹（如点阵地图）属于模板本身，不是残留。

没有 PowerPoint 时用 WPS 转图；只有 LibreOffice 时可以转图，但微软雅黑会被替换，字是否装得下以 WPS 或 PowerPoint 打开为准。


## 目录验收

- 打开每份目录页：条目须为新大纲（如「一、我的需求」…），不得仍是模板旧章（如「一、业务背景」）。
- `toc_entry_count=0` 的「一、」型模板须走模式 B；assemble 报告 `toc.status=filled` 且 `mode=chapter|badge`。
