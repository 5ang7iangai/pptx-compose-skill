# 增量改稿

在现稿上加一页、加一章、改字、挪形状。所有命令都写出新文件，不覆盖原件。页码是放映顺序，从 1 起，不是文件名里的数字。插入默认发生在致谢页之前，没有致谢页则加在末尾。先复制页，再改字。

必填和可选项、何时先问用户，见 [SKILL.md](../SKILL.md)「新建和改稿」。版式对应哪种风格见 `catalog/pairing.yaml` 和 `catalog/图库.html`。颜色跟模板标题和顶栏，不写进 spec。

小改动都在 `slides.py` 一个入口里，一个子命令一种操作；运行 `python scripts/slides.py -h` 看全部。

## 加一章（一条命令）

把克隆哪一页、改哪些字、删不删旧图、新图的 brief 写成一份 spec（字段见 [spec.md](spec.md)）。页码和原文都从这次的模板里量：

```text
python scripts/add_chapter.py 模板.pptx -o 编制.pptx --spec 章节.json [--regen] [--fix]
```

依次做：克隆扉页和正文样例页 → 每份目录加新章条目 → 按 `replacements` 改字 → 按 `remove_pics` 删旧图 → 大模型出 SVG（检查不过就修补）→ 写图片版和可编辑版。

产出：

- `编制-图片版.pptx`、`编制-可编辑版.pptx`

目录状态和每张图的检查问题打在屏幕上，不另写文件。

已有 SVG 时默认复用，不调模型；`--regen` 全部重出；`--fix` 只把没过检查或写了 feedback 的交给模型修补。某一页单独重出，用 `edit_spec.py 章节.json 3 --regen`（页码是 spec 里的第几张正文页）。

只要克隆、不填字不出图时：

```text
python scripts/slides.py add-chapter 模板.pptx -o 编制.pptx --title "四、新章节" --anchor "三、" --divider 14 --pages 6,7,8,9
```

- `--divider`：章节扉页样例，可以不给。`--pages`：正文样例，按这个顺序克隆。
- `--anchor`：目录上已有的一条章节文字，用来复制样式。选最短、能唯一定位的那一条。
- 每份含「目录」或 CONTENTS 的页都加标题，包括新克隆的扉页；已有同样标题的页跳过。新扉页上新标题用当前章色块和白字，锚点改回普通条目。已有章节的编号不另做替换。
- 返回 JSON 里有新页序号（`created`）和目录条目状态（`toc`）。接着对新页 `fill`，新图按 [结构图.md](结构图.md) 出。

量间距、两套外观的做法见 [文案与目录.md](文案与目录.md)。

## 加一页

```text
python scripts/slides.py add-page 模板.pptx -o 编制.pptx --clone 6
```

然后只改这一页的文字槽。用户没要求改目录时，不动目录。

条目变少，删掉多余形状，不只清空文字；条目变多且结构相同，复制一组再改字：

```text
python scripts/slides.py delete-shapes   编制.pptx -o 编制2.pptx --slide 24 --match 多余卡片里的原句
python scripts/slides.py duplicate-shape 编制.pptx -o 编制2.pptx --slide 24 --match 要复制的那条原文 --dy 0.8
```

`--dx`、`--dy` 是相对原形状的英寸偏移。原形状在组合内部时，偏移按组合内部坐标。

## 改文字

```text
python scripts/slides.py fill 编制.pptx -o 编制2.pptx --map 替换.json
```

map 格式见 [spec.md](spec.md) 最后一节。替换写在原有文字块上，保留首段的字体和颜色。

实操纪律：

1. **字数先校准**：替换前比较原文字数，新文字不超过原版 ±10%。导语框高度有限，超长会溢出。
2. **卡片用 `paragraphs`**：原卡片通常是段落 0 粗体标题 + 段落 1 描述。用 `"paragraphs": ["新标题", "新描述"]` 保持各段格式；`"text": "标题\n描述"` 会让所有段落继承同一个格式。
3. **先删图再画图**：克隆页带着原产品的架构图或截图。`remove_pics: true` 删除正文区（上沿低于 2 英寸）的旧图，`diagram` 在同一区域放新图。
4. **bbox 量旧图**：`diagram.bbox` 取原页面图片的位置，从风格卡的 `pictures` 或 `inspect_slide.py` 读，不凭经验猜。

## 目录

不加正文、只补目录：

```text
python scripts/slides.py add-toc-label 编制.pptx -o 编制2.pptx --title "四、新章节" --anchor "三、"
```

条目若和旧字重叠，返回里 `status` 为 `overlap`。预览里叠字时挪到空位：

```text
python scripts/slides.py move-shape 编制.pptx -o 编制2.pptx --slide 2 --match "四、新章节" --x 0.6 --y 6.2
```

`move-shape` 用于顶层文字块。手摆目录不拆开原有组合。三份目录都要看。

## 重排

```text
python scripts/slides.py clone  编制.pptx -o 编制2.pptx --clone 5 --clone 6 --before 9
python scripts/slides.py move   编制.pptx -o 编制2.pptx --slide 20 --before 18
python scripts/slides.py delete 编制.pptx -o 编制2.pptx --slide 19
python scripts/slides.py pack   解包目录 -o 编制.pptx
```

删除会去掉该页专用的备注。图片若仍被其他页使用，会保留。
