# 兜底排版（没有大模型时）

正常流程是大模型出 SVG、再出两版 pptx（[结构图.md](结构图.md)）。只有没有大模型配置（找不到 `config.yaml`）时，才用 `draw_diagram.py` 按七种固定版式排方块，并**告诉用户这是简版**。代码在 `scripts/fallback/`。

```text
python scripts/draw_diagram.py 输入.pptx -o 输出.pptx --slide 12 --spec 图.json --svg <原名>-图/12-示意.svg [--style 风格卡.json] [--pic 1]
```

- 颜色和字体缺省时从该 pptx 现抽；已有风格卡时加 `--style`。
- `--pic 1`：用该页第 1 张图片的外框，画完删掉这张图片（必须是顶层图片）。没有旧图时在 spec 里写 `bbox`（英寸）：`{"x":0.6,"y":3.2,"w":12,"h":3.6}`。
- `--svg` 不是可选的美化项：它和形状读的是同一次排版结果，两份天然一致。没加 `--svg` 时只有形状版，交付前要补跑。

形状版是一个名为「结构图」的组合。每个标签是独立文本框；箭头是连到图元上的连接符（矩形连接点：0 上、1 左、2 下、3 右），可以用 `validate_deck.py --diagram-slide` 查。不复刻渐变、阴影、蜂窝底和写实小图标，也不收成一排没有说明的纯色方块。七种之外的图，拆成最接近的一种，套下面的样式甲或乙；拆不开就停下来问。

## 七种版式

**pipeline**：从左到右。需要枢纽时把 `mode` 设为 `hub`，节点用 `place`：`left`、`center`、`right`。

```json
{"layout": "pipeline", "mode": "row", "nodes": [{"id": "a", "text": "材料"}, {"id": "b", "text": "风格卡"}, {"id": "c", "text": "页稿"}]}
```

**cards-steps**：上方卡片、中间步骤、下方结果，某一段可以空着。

```json
{"layout": "cards-steps", "cards": [{"title": "材料散在多处", "body": "旧幻灯片、Word 和纪要对不齐"}],
 "steps": ["汇总口径", "排好章节", "改到同一版"], "results": ["目录正文一致"]}
```

**bands**（样式甲）：左侧层标签，右侧每块是标题加一行说明。某层要强调时加 `"emphasis": true`。

```json
{"layout": "bands", "layers": [
  {"name": "使用入口", "items": [{"title": "拿出幻灯片", "sub": "用正在讲的这一套"}]},
  {"name": "交稿核对", "emphasis": true, "items": [{"title": "目录扉页一致", "sub": "正文和图一起改"}]}]}
```

**layers**（样式乙）：左侧层级名，右侧横条里的小卡片。

```json
{"layout": "layers", "layers": [{"name": "用户交互", "items": ["给出模板", "确认页纲"]}, {"name": "编制", "items": ["抽风格", "写正文", "画图"]}]}
```

**flowchart**：`kind` 取 `start`、`process`、`decision`、`end`；`row`、`col` 指定格子，从 0 起；分支放在右边的列。

```json
{"layout": "flowchart",
 "nodes": [{"id": "s", "kind": "start", "text": "开始", "row": 0, "col": 0},
           {"id": "d", "kind": "decision", "text": "缺内容", "row": 1, "col": 0},
           {"id": "p", "kind": "process", "text": "补全并标待核实", "row": 1, "col": 1},
           {"id": "e", "kind": "end", "text": "结束", "row": 2, "col": 0}],
 "edges": [{"from": "s", "to": "d"}, {"from": "d", "to": "p"}, {"from": "d", "to": "e"}]}
```

**tree**：一个根，一行子节点，每个子节点下面可以再有一行孙节点。

```json
{"layout": "tree", "root": {"text": "演示材料编制助手"},
 "children": [{"text": "抽风格", "children": [{"text": "色"}, {"text": "字"}]}, {"text": "画形状", "children": [{"text": "分层"}]}]}
```

**chevron-matrix**：顶部一行燕尾，下面每列若干矩形，`columns` 与 `phases` 对齐。

```json
{"layout": "chevron-matrix", "phases": ["识别", "清洗", "输出"], "columns": [["读材料"], ["改文字"], ["形状图", "校验"]]}
```

## 样式参数

颜色用风格卡里的 `dominant`、`accent`、`light`、`surface`、`text`。示例模板上 dominant 接近 `006F6B` / `007774`，不改用主题里的办公蓝。字：中文 `fonts.ea`，西文 `fonts.latin`。

下表取自 示例模板配套的《“人工智能+业务”应用建设实践-示例模板》第 3、5、11 页。这几页的图在源文件里是整页贴图，下面数值是对照截图目测的区间，不是 XML 精确值。新模板的典型图如果是形状，直接读 `prstGeom`/`avLst`/`ln`/`solidFill` 拿精确值；是贴图就同样目测，并在页纲里注明「目测估值」。

| 参数 | 样式甲（bands） | 样式乙（layers） | 流程图 |
|---|---|---|---|
| 圆角 | 8–12 磅 | 8–10 磅 | 6–8 磅（判断用菱形） |
| 边框 | 浅青绿细边约 0.75 磅；深色条无边或同色边 | 层标签无边；卡片无边或极浅边 | 深色细边约 1 磅 |
| 卡片最小高度 | 0.55 英寸 | 0.5 英寸 | 0.4 英寸 |
| 层标签/标题字号 | 11–12 磅 | 层名 11–12 磅 | 节点文字 11–12 磅 |
| 卡片正文字号 | 12–14 磅标题 + 10–11 磅说明 | 12 磅 | 不单独设说明行 |
| 层间距 | 小于卡片高度，整列左缘对齐 | 同左 | 同一列节点间距约 0.12 英寸 |
| 箭头 | 细线深色，连到卡片边缘 | 向下，dominant | 正交，三角箭头 |

改 `fallback/draw.py` 里这几个版式的默认参数时，这张表一起改。

**样式甲：分层色带**（模板第 3 页「业务场景分析工作思路」）

- 外框：白底或浅底，浅青绿细边，圆角约 8–12 磅；不用无边的大色块铺满。
- 层标签：深色小胶囊，白字，写在该层左侧或左上，如「L4 业务场景」，字号小于卡片标题。
- 普通卡片：白或浅灰底，细边或很浅的底，左对齐；标题一行，下面一行灰色小字说明。可有一个简单的小图标；没有图标时不留空洞。
- 强调条：同层里需要对比的两三项，用深色宽条，白字标题，浅色小字说明，垂直居中。
- 层与层之间留稳定的缝，缝小于卡片高度，整列左缘对齐。层间有方向时用细的深色箭头连到卡片边缘，不悬空。

**样式乙：层级矩阵**（模板第 5 页「模型—元数据—指标—思维链—分析报告」）

- 左侧窄标签：层名加数量，浅灰底，深色字，垂直居中。
- 右侧同层若干等宽圆角矩形，浅灰底，深色字，水平垂直居中，无深色边。
- 层与层之间一条向下的 dominant 箭头。最右侧若是系统截图，保持图片。

**流程图**（模板第 11 页）：白底、深色细边、文字居中。开始和结束用圆角，判断用菱形，箭头正交，「是 / 否」写在线旁，框内文字两行以内。

**两套配色**，一份幻灯片只用一套：

| | 深色强调 | 浅底卡片 |
|---|---|---|
| 甲，适合总览和对比 | 填充 dominant，白字，无边或同色边 | 填充 surface 或白，字用 text，边用 light |
| 乙，适合矩阵和步骤 | 只用于层标签或当前步骤 | 填充 light，字用 text，边可以没有 |

不为塞进框里把标题缩到看不清；放不下就改短句子，或改成两行，两行都是完整的词。

## 表格和图表

模板里有表格页，就克隆那一页再改单元格文字，不新画一套表。模板里没有表格而用户要求时，用 `dominant` 做表头、`surface` 做表体，画成原生表。有数据的图表做成原生图表；没有数据的曲线截图保持图片。
