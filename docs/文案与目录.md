# 文案与目录

加页、加章、改图之前先读当次模板里的同类页，再写字、再画图。幻灯片是给业务人员看的，不写实现方案里的词。

## 1. 目录和重复元素

通用原则：**往任何一组重复元素里加新的一项之前，先量旧元素，不凭经验给固定值。** 目录最常见，一排卡片、一列步骤、一组图例同理：挑一个最像的邻居，量出它的 x/y/w/h、字号、字色、对齐、填充、与前后邻居的间距，新元素套这一组数值。四步：找邻居 → 量数值 → 套数值 → 两套外观都要对。

目标：新条目看起来像原来那一列里的下一项，而不是另做的一个按钮。以示例模板目录为例：

1. 找出同一页、同一列的已有条目（示例模板上是「一、」「二、」「三、」这种短标题）。
2. 记下每一个的 x、y、w、h，以及相邻两条的间距。新条目用**锚点上方那一档间距**，不用固定值。示例模板第 2、5、14 页实测：条目高 0.75 英寸、宽约 4.83 英寸、x 约 5.72–5.78；「一」到「二」间距 0.67，「二」到「三」间距 0.48。第四项接在「三」下面约 0.48 英寸，并躲开页脚色条。
3. 记下两套外观，缺一不可：
   - 当前章：实色填充（示例模板为 `006F6B`），白字（主题 `bg1`），约 25 磅，左对齐，垂直居中，直角矩形。
   - 其余章：无填充，字色 `006F6B`，字号、对齐、垂直居中与当前章相同。
4. 新扉页：新标题用「当前章」这一套，上一章改回「其余章」，字色也要改回深青绿。只改填充、不改字色，白字会消失。
   **高亮必须成套**：强调底 + 对比字一起改；禁止只改字色或只改底。写回 OOXML 时若样板带 `noFill`，套实心底后要删掉 `noFill`，否则微信/部分预览里底色不显示，当前章像缺了。
5. 其它目录页：新标题只用「其余章」，不改该页原来的高亮。整套新编里每一页目录都标出它后面的那一章：模板里条数少的那套是当前章，条数多的是其余章，字色和填充一起换。不要把当前章的颜色写死。
6. 内部文字的对齐跟着条目走，样例左对齐、垂直居中，新条目也是。
7. 条目数变了（比模板多或少）以后，整组条目（所有编号块和章名作为一个整体）要上下居中：对齐左侧「目录 / CONTENTS」那组字的纵向中心，认不出时对齐页面纵向中心。条目之间仍用量出来的间距，只整体平移，不沿用模板第一条的顶部起始位置。少了条目还贴在上面、下面空一大块，就是没做。`fill_toc` 填完会自动调用 `slides.center_toc` 做这一步；手工加减条目后也要再跑一次。

`slides.py add-chapter` / `add-toc-label` 按这一列的实测间距往下排，并在新扉页上交换当前章样式。排完仍要打开看：间距是否和上面几条同一节奏，字色是否看得见，有没有压住页脚。

## 1.1 正文页签与旧章名

克隆样例页时，顶栏或侧栏常有模板课题的章节导航（如「问题及需求 / 服务思路 / 产品特色 / 服务成效」）。**这些不是标识，必须改成本稿大纲对应的章名**（可用短名以适配框宽），并按本页所属章高亮对应页签；量邻居的字号、字色、填充再改。留着旧词会让读者觉得目录与正文章节不一致、像漏了一章。logo、组织标识、装饰线除外。

改完文字后还要**按原页签槽位重排**：等宽或按字数加权（`by_chars=True`），覆盖原导航条起止；相邻页签必须 **edge-to-edge（gap=0）** 紧挨，禁止留缝、禁止重叠。可用 `slides.relayout_section_tabs`（默认 `gap=0`）。

导语下方的卡片或结构图应横向铺满内容区或居中对称，不要竖叠挤在一侧留下大片空白（目录/封面/致谢除外）。

## 2. 封面标题

- 标题框不横向占满整页：宽度不超过页宽约 75%，以原标题框中心左右居中，两侧留白。
- 一行放不下就按语义断成两行：断在标点后，或「及 / 与 / 和 / 暨」这类连接词前，靠近中间；不拆开引号、书名号、括号里的词，也不拆西文单词和数字。末尾的括号注释整段放第二行。
- 字号先保持模板原值；两行仍放不下才略缩，最多缩到原来的八成。行距按单倍，文字在原标题区域内上下居中，不压下方的装饰线和底图。
- `pptkit/autofill.fit_cover_title` 落实以上几条，整套新编填封面时自动调用；`cover_title_room` 按这个宽度和两行估算标题能放几个字。

## 3. 正文怎么写

目标：读者不看讲解，也能看懂这一页在说什么业务、卡在哪里、准备怎么做。

先读被克隆的那一页以及相邻正文页，记下：

- 导语在哪个框、大约多少字、几句话、字号和对齐。
- 有没有加粗的关键词、有没有「一是 / 二是」或「（一）（二）」。
- 卡片或要点是一行还是两行，每条大约多少字。

新文字跟这个量级走，不换成一句口号。参照两份已有成稿的写法，不抄句子：

| 来源 | 导语 | 写法 |
|---|---|---|
| 示例模板正文（如第 6–9 页） | 约 110–200 字，16 磅量级，两端或左对齐 | 先写现状，再写矛盾，再写要做的事或已经做到的事。关键词加粗 |
| 《“人工智能+业务”应用建设实践-示例场景》 | 约 110–200 字，16 磅，左对齐；少数页用（一）（二）分条 | 一个具体场景、一个具体做法、一个能看懂的结果。数字只写材料里有的 |

一页正文至少三层，能放进原有文字框：

1. 导语：写成一段话，两到四句连起来，接近样例页的字数。先说这件事做到哪一步，再说做法，最后点出结果或听众该记住的一点。不要按材料的换行，一行一句地搬。专名和数字用材料里的原值，说法改成汇报、介绍或交流时说得通的一句。
   导语必须装进导语框内行数，不能溢到下方结构图上；字放不下就删短到框能装下，或加大框并下移结构图 bbox（见 [结构图.md](结构图.md) 贴图间隙、[校验与验收.md](校验与验收.md)）。
2. 要点：每条是用户能感到的一件事，长度接近同页样例卡片（常见两行、十几到二十几个字）。
3. 图：图上的词是导语里已经出现过的业务对象，不另造缩写。

不写进幻灯片的词：套版、搬字、风格卡、克隆、外框、零件、落盘、脚本。这些是制作说明。用户听到的是材料散、口径要重对、改一张图就要重出一页。

问题页用用户的工作场景来写，例如：

- 同一件事写在旧幻灯片、Word 和纪要里，汇总时对不齐。
- 换一版介绍，目录、扉页和正文要一起改，容易漏一处。
- 流程画在图里，改一个说法就要整张图重做。

服务思路页写清输入、处理、结果，各用业务名词。特色页写用户能点到的能力，每项配一句它解决哪件事。成效页只写这次能核对的事实；没有的部署范围、节省时间标「待核实」，不编造。

同一章里平级的小节（如（一）（二）（三）（四））每个单独成页，用同一种页型和表现方式：克隆同一类样例页，前面的有导语加图，后面的也是导语加图。不要因为后几项材料少，就把它们并成一页纯文字。材料少时导语仍写成一段、贴近同章其他页的字数，图用两三条并列举措（能力阵列等），内容只取材料原文。

加一章时，正文页数跟这份模板自己的节奏走。有的模板是「问题、思路、特色、成效」四页，有的不是。克隆它自己的样例页，不把某一套页签写进别的模板。

## 正式汇报表述与重点强调

- 导语、卡片标题与说明面向正式汇报听众：句子完整、得体，信息准确前提下写完整；避免口语口号堆砌或过碎短句拼盘。
- 重点工作、关键名词（如企业底板、模板学习、结构图、版式、风格、图片版、可编辑版、两套 pptx、校验等）在导语与结构图文字中用**加粗**或**模板主色**强调，整段不要同色同粗。
- 导语可用 `pptkit.fill.emphasize_keywords`；结构图 brief 用【关键词】标记并由模型以 tspan 主色加粗绘制。
