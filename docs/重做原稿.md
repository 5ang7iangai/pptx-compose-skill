# 重做原稿

用户给一份现成的稿子，要把其中几页的结构图重画（转成可编辑形状、换成更清楚的图），其它页不动或只留选中的页。默认不跑，用户明确要求时才做。

```text
python scripts/redraw_pages.py 原稿.pptx -o 编制.pptx --spec 重做.json [--regen] [--fix]
```

依次做：按页清掉图区旧形状/旧图（保留标题和点名保留的导语）→ 按 `resize` 调导语框 → 只留 `keep_slides` → 大模型出 SVG → 写图片版和可编辑版。产出同加一章，只有两版 pptx。图片文件名在生成过程中用**新稿页码**，spec 里写的是**原稿页码**。

spec 字段见 [spec.md](spec.md)「重做原稿」一节。风格和版式从 `catalog/` 选，配色从这份原稿的主色来，不套用别的稿。

## 1. 先看原图

1. `python scripts/preview.py 原稿.pptx 预览/ 4 5` 导出原页截图，局部放大看清：结构（谁在左、谁在右、各占多宽）、元素造型（水滴图标、下划线小标题、无边框说明）、箭头走向、旁注位置、颜色分级。
2. `python scripts/inspect_slide.py 原稿.pptx 4 5` 列出每个顶层形状的位置（英寸）和文字，用来定 `bbox`、`clear`、`keep_match`、`resize`。
3. 风格卡里图片 `kind` 为 `diagram` 的才重绘（见 [模板分析与风格卡.md](模板分析与风格卡.md)）。原图是原生形状拼的也一样，`clear` 会清掉。标识、截图、扫描件、底纹、曲线不动。

## 2. 写 brief

- **版式、左右比例、元素样式大致跟原图走**。不要求 100% 相同，但用户没要求就不换风格、不换结构。只重画一半（如左侧照原图、右侧新画）时，整页仍要排满，中间不留空列。
- brief 开头写「参照原图版式」，再写各部分宽度比例和高度预算。
- 版面复杂（多级架构、并排说明 + 架构）时直接给**坐标骨架**：按画布 1200 宽、高按 bbox 比例，写各框 x/y/w/h、箭头起止点、旁注基线，模型照着摆，允许 ±8 微调。这比只写比例稳得多。
- 原图有、SVG 画不了的（照片、渐变）换成线条图标、实色，其余尽量对上。不加原图没有的标题、副标题、说明行。
- 关键词加粗变色时，在 brief 里用【】标出并说明「画图时去掉括号」，同一个 `<text>` 里用 `<tspan>` 加粗变色。
- 长条目放不下时，宁可调列宽、调字号到下限，也不让模型自行删字；条目有重复后缀时可省去后缀并加图注。
- 字号写原页正文的磅数（`fonts`），字体用风格卡的 `fonts.ea`（任务脚本自动取）。
- 配色跟原稿标题和顶栏，不用在 spec 里写颜色。分级色在 brief 里用 `{c2}`、`{c3l}` 点名（见 [结构图.md](结构图.md)「配色」）。
- 不换风格时，把这一版式现在用的 `style` 写进 spec。不写则用 `catalog/pairing.yaml` 的预置。

版面分成左中右时，brief 可以这样写：

```text
参照原图版式：左列服务对象（约占宽 18%）→ 中间大圆（约 28%）→ 右列三张要点卡片（约 50%），三部分之间用连线衔接，不留空列。
左列 5 个服务对象，自上而下等距排满整列高度：每个是白底圆角小卡片（浅阴影），左边一个 {mid} 线条图标，右边名称……
中间大圆：{c2} 实底，外面一圈 {c2} 细虚线装饰环。……示意和两行字作为一个整体在圆里上下居中，全部离圆边至少半个字号。
```

## 3. 清图区

| 写法 | 效果 |
|---|---|
| `"clear": "bbox"`（默认） | 只清中心落在 `diagram.bbox` 里的顶层形状和图片。没字的通栏大底框留下 |
| `"clear": "all"` | 清掉页上所有带位置的顶层形状，标题占位符除外 |
| `"keep_match": ["导语开头几个字"]` | 文字含这些片段的形状不清 |
| `"resize": [{"match": "导语开头", "w": 12.3}]` | 改第一个含该文字的形状的 x/y/w/h（英寸），如图变宽后导语跟着拉宽 |

报告里 `cleared` 按原稿页码列出清掉的形状数。

## 4. 调到满意

导出预览逐页和原图对比。检查查不出的问题（箭头方向反了、模块画重、留白不匀、图标太小、和原图差太多），写成可执行的意见：

```text
python scripts/edit_spec.py 重做.json 5 --feedback 意见.txt     # 页码 = 原稿页码，意见每行一条
python scripts/redraw_pages.py 原稿.pptx -o 编制.pptx --spec 重做.json --fix
python scripts/edit_spec.py 重做.json 0 --clear                 # 满意后清掉 feedback / regen
```

要整张重出：改 brief，再 `edit_spec.py 重做.json 5 --regen` 后重跑。
